# ペア卓

8人までの部屋で、4つの卓に分かれて **1対1** のミニゲームをするラウンジです。席にいない人も、部屋の中ならどの卓も観戦できます。

## 遊び方

1. **部屋を作る** と、6文字の部屋コードが出ます。それを友達に渡します。
2. 友達は **部屋に入る** で同じコードを入力します。部屋は **8人まで** です。
3. 空いている席に着きます。一卓は2席です。
4. 二人そろったら、同じミニゲームを選びます。揃った瞬間に始まります。
5. 対局中に席を立つと、不戦敗です。
6. 座っていない人は卓を選ぶだけで観戦できます。対局中の人も、ほかの卓を見に行けます。自分の番が来たら、画面下から戻れます。

オフライン練習では、空席に CPU を置いて1人でも試せます。`?demo=spectate` は CPU 同士の対局を最初から観戦します。

### ミニゲーム（すべて1対1）

| ゲーム | ルール |
| --- | --- |
| あっち向いてホイ | じゃんけんのあと、負けた人が向く方向を勝った人が当てる。当たると勝者の1点。2本先取。手と方向は両者が出すまで非公開 |
| 反射神経 | 合図が出てから先に押す。早いとお手つき。2本先取 |
| 重力付き4目並べ | 駒は選んだ列の一番下に落ちる。縦横斜めに4つ揃える |
| ハイ＆ロー | 次の札が大きいか小さいか。3点先取。予想は両者が出すまで非公開 |
| エアホッケー | 板を左右に滑らせて跳ね返す。球の速さは一定で、数は増える。3回逃すと負け |
| ホールバウンド | 落ちてくる球を押すと相手側の上から落ちていく。球は増え、3個落とすと負け |

## 通信

[MkMk Street](https://github.com/makimaki510151/MkMk_Street) と同じ方式です。

- [PeerJS](https://peerjs.com/) 1.5.4（WebRTC DataChannel、reliable）
- ホストの Peer ID は `minigames-部屋コード`
- 状態を更新できるのはホストだけ。ゲストは操作を送り、全員同じスナップショットを受け取る
- バージョンが違う相手は入室できない
- 切断しても同じ名前なら、しばらく席を残して再接続できる

未公開の手（あっち向いてホイのじゃんけんと方向、ハイ＆ロー）と山札は、スナップショットに含まれません。観戦者にも見えません。

## 開発

静的ファイルだけです。ビルドは不要です。

```bash
python3 -m http.server 8080
```

テスト:

```bash
node --test tests/*.test.mjs
```

GitHub Pages で公開する場合は、Branch を対象ブランチ、Folder を `/ (root)` にしてください。
